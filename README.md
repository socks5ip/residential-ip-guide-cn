# 住宅 IP 选型与接入指南

> 面向跨境电商、社媒运营、广告验证等场景，整理住宅 IP（Residential IP）与静态住宅 IP 的选型、接入和常见问题。

住宅 IP 是由 ISP 分配给家庭用户的真实 IP 地址，通常比机房 IP 具有更高的匿名度和更低的业务风控概率。本仓库收集国内外主流住宅 IP 资源、协议接入方式以及典型场景的选型建议。

## 内容范围

- 住宅 IP 与机房 IP 的区别
- 静态住宅 IP vs 动态住宅 IP 的适用场景
- 美国、香港、日本、韩国、德国等地区住宅 IP 推荐
- SOCKS5 / HTTP / L2TP 协议接入示例
- 住宅 IP 常见使用问题 FAQ
